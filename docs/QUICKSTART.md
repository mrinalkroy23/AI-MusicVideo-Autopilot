# Quickstart

1. Install Python.
2. Install Ollama.
3. Install FFmpeg.
4. Install requirements.txt.
5. Start Streamlit app.
6. Upload MP3.
7. Transcribe audio.
8. Segment lyrics.
9. Generate scene plan.
10. Generate prompts.
11. Generate images.
12. Build final video.

Target workflow:
MP3 -> Whisper -> Lyrics Segmentation -> Scene Planner -> Prompt Generator -> Images -> Video
