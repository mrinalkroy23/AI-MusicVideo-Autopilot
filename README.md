# AI-MusicVideo-Autopilot

Fully local AI music video generation pipeline for Mac Mini M4 and similar systems.

## Vision

Upload an MP3 -> Transcribe with Whisper -> Generate storyboard with Ollama -> Generate images -> Build cinematic video automatically.

## Planned Stack

- Whisper
- Ollama (Qwen3)
- FLUX image generation
- FFmpeg
- Streamlit Web UI
